# 模型选型（按产物分流）

先确定这次要交付的产物，再选模型。模型能不能用取决于**本机或云端实际部署清单**；本文件只给选型规则与能力边界，不保证某个型号在目标环境可用。清单会变，生成前应现查一次实际可用模型。

## 一、按产物分流

| 产物 | 首选路线 | 备选 | 不要用 |
|---|---|---|---|
| 静帧、关键帧、参考图，改景别或改质感 | 图像编辑模型 + 少步蒸馏 LoRA（带参考图） | 云端图像模型（本地失败或风格不合） | 纯文生图基座做身份延续 |
| 单镜头视频（≤15s，一张首帧即可说清） | 首尾帧图生视频 + 快速 LoRA | 参考生视频（需要多参考图时） | 把多张参考图硬塞给只吃首/尾帧的模型 |
| 身份锁定、多参考图、按素材时间线排参考 | 参考生视频 + 少步 LoRA | 图生视频配关键帧 | 用多段视频 RGB 拼接冒充连续长镜 |
| 单镜超长或内存不足 | 分段采样（段间 latent 续接） | 缩小画布后单次生成 | 生成两段后直接拼接 |
| 角色配音（已有可用音色） | 本机克隆音色（0.6B 级） | 预设音色 | 用上一段视频里的原生出声跨镜复用 |
| 角色配音（没有音色素材） | 预设音色 | 音色设计模型造声后固化为参考样本 | 借用其他角色的克隆音色 |
| 音乐、环境声、群杂 | 本机音频模型或云端音乐服务 | 素材库 | 用角色配音模型硬唱 |

## 二、图像

- **选型**：需要保构图/保身份时用图像编辑模型，并且**必须给参考图**；只给文字会按文字重画。
- **参数**：少步蒸馏 LoRA 按训练步数使用（常见 4 步），cfg 1.0 一类的蒸馏契约不要自行加大步数——画面会发糊，且不保证文字更准。
- **适用**：改景别（近景推特写）、改质感（广告图→实拍剧照）、换装、同场景补角度、灰底参考重绘成实景。
- **不适用**：屏幕/字幕/车牌/手写名单等需要逐字保真的画面（文字会变乱码）；人脸特写（容易换脸）；车内驾驶位（舵位可能被改）。
- **写法**：编辑模型的文字指令优先级高于参考图。要保身份就只写“面容严格复现参考图”，不要复述五官、脸型、年龄，写了就按文字重画。
- **接入新 LoRA 前**：先在同一张参考图上做 A/B，确认没有改脸、改服装、改构图再进生产。

## 三、视频

- **图生视频（首帧锁定）**：适合单镜、动作清楚的镜头；可用首尾帧约束落点。参考图只吃首帧/尾帧，堆更多图没有用。
- **参考生视频（多参考图 + 时间线）**：适合多人同框、身份锁定、按素材时间线排参考、上一段末帧续接。开销更大，单首帧能说清的镜头不要上。
- **画布与时长**：先定交付比例，再按内存预算选分辨率；单段帧数受模型对齐规则约束（常见为固定步长的等差数列，例如 `5 + 17n`）。分段时长超过单段上限时走分段采样，不要拼接。
- **音频**：视频模型自带的原生音频只作参考；角色对白另有配音链路时，不要让两套声音同时进入成片。
- **未实测的能力**（二采放大、额外引导、实验节点）：先单段小样验证再进生产，未验证前按不可用处理。

## 四、音色与音频

| 路线 | 什么时候用 | 一致性来源 |
|---|---|---|
| 预设音色 | 配角、旁白、临时试音、没有音色素材 | 同名预设=同一份“声音身份证” |
| 克隆音色 | 主角、需要演出层次 | 同一段参考音频 |
| 音色设计 | 只有文字描述、要一个不存在的声音 | 生成一次后固化为参考样本，再走克隆 |

- **一个角色只有一个音色来源**；换源等于换人。
- **采样率统一**（例如全链路 32 kHz），混采样率会让音频拼接节点直接失败。
- **变速对齐有上限**：超过约 1.12 倍就拆句，不要压速硬塞。
- **长片优先预设音色**：克隆音色在长片里更容易出现拖长音与漂移。
- 声音资产的建立、试音样音组与审听状态属于资产合同工作，不在本技能内；本技能只负责选路线、记模型标识与参数。

## 五、本地与云端

- **同一场戏不混源**：本地与云端的噪点、色偏、镜头语言不同，整场只用一边。
- **同一角色不混声**：角色对白只走同一条配音路线。
- **云端只救场不接管**：单张图、单镜可以送云；整场迁移会毁掉全片一致性。
- 需要画面内文字准确、需要 15–30s 长镜头、或本地反复失败时，才切云端对应品类；切之前确认授权与费用。

## 六、运行约束

- **同一时刻只跑一个生成任务**：内存守卫触发时会向服务发送中断，会连带打断手头的测试任务。
- **提交前看可用内存**：长段、高分辨率、多参考图都会抬高峰值，先估算再提交。
- **一次只验证一个变量**：换模型、换步数、换画布分开做，否则失败后无法归因。
- **记录可复现信息**：模型文件名、LoRA、步数、cfg、画布、帧数、种子。

## 七、常见坑

- **蒸馏 LoRA 不能加步数**：训练步数之外的使用属于契约外，画面会变差。
- **编辑模型不是重绘模型**：文字指令写多了会覆盖参考图身份。
- **首尾帧模型不吃多参考**：堆图只会让约束互相打架。
- **原生音频与配音链路争声道**：成片只保留一条对白来源。
- **分辨率与对齐规则不匹配**：先按模型要求算画布与帧数，再谈构图。
