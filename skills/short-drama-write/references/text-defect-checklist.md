# 交稿前文本自检

这份清单只查**可机械确认的文本问题**，不判断审美。写完一集先跑一遍，再交人审；发现问题回到剧本正文修，不用说明文字解释。

## 1. AI 使用边界

AI 可以提效，但不能替作者做判断。交稿前确认这一集的责任归属。

| 可以交给 AI | 必须由作者完成 |
|---|---|
| 原著章节摘要、资料与人物关系初步梳理 | 判断原著价值、提炼一句话核心卖点 |
| 选题方向、片名、桥段、台词的备选方案 | 改编方案、开篇重构与分集结构 |
| 局部初稿扩写、同一段台词的多版本 | 情绪节奏与钩子分布 |
| 错别字、格式、基础连续性初检 | 关键转折的因果设计 |
| 可数的机械核对（字数、场次、标签） | 终稿逐场精修、通读校对与 AI 痕迹清理 |

出现下列任一情况，说明这一集需要人工重写而不是继续润色：前后对白承接不上、凭空出现前文没演过的对话、所有角色一个口吻、只推进打脸升级而事件之间没有因果。

## 2. 台词辨识度

**抹名测试**：删掉每句台词前的角色名，只看台词内容，仍能分辨是谁在说话。做不到就说明：

- 所有人共用一套句式与词汇（都端着、都爱讲大道理、都用同样的反问）；
- 台词只表达态度，不携带身份、处境、关系或信息差；
- 台词可以整段挪给另一个角色而不违和。

修法：先定每个角色的说话方式（句长、称呼、回避什么、什么时候沉默），再回改台词；不要靠加口头禅制造区别。

## 3. 一个信息只讲一次

- 同一信息不在相邻场次重复解释；需要强调时改变的是**处境**，不是复述。
- 角色来回表态、反复确认、互相拉扯却不产生新信息或情绪推进的段落，整段删掉。
- 已经用动作演过的内容，不用台词再讲一遍。
- 对白必须产生变化：改变判断、暴露筹码、转移权力、推进决定，任一即可。

## 4. 模板痕迹与占位文本

- 占位台词（如「此处可加冲突」「待补」「类似上一场」）零容忍，交稿前必须清零。
- 重复段落：同一段对白、同一组动作在集内或跨集重复出现。
- 模板化对白：换成任何项目都成立的万能句，尤其「必出金句」式的强行上高度。
- 书面腔与翻译腔：非风格选择时改成口语；说明书式旁白改为动作或 `[VO]` 的明确动机。

## 5. 文本事故

逐集检查，这些是纯机械错误但最容易被退回：

- 整集缺失，或单集内大段内容缺失（场景跳号、对白中断）。
- 集间错贴：上一集内容粘到下一集，或集号与内容不对应。
- 前后承接不上：上一集退出状态与本集进入状态矛盾（伤势、时间、持物、关系、地点）。
- 标签事故：`[OS]`、`[VO]`、`[SFX]`、`[画面文字]` 混用或该有的没有。
- 台词块与动作叙述混淆（含冒号的动作被写成对白）。

## 6. 交付完整性

- 使用平台统一模板，场景、对白、画外音、画面描述字段填满。
- 集数连续，编号与分集地图一致，不缺集、不重号。
- 连载项目标注首发集数与更新安排；系列剧标注季边界。
- 目标时长有要求时，按真实表演与停顿估算，不用统一字数凑。

## 7. 自检记录

交稿时用三行说明即可，不写成长报告：

```text
规模：本集 N 场 / 约 M 字；累计集数 X / 总字数约 Y（对照交付档：达标 / 差 N 集 / 差 M 字）
自检：抹名测试通过；重复与占位已清零；集间承接核对无矛盾
未决：列 0–3 条需要作者决定的事项（没有则写「无」）
```

数字只报可数事实，不猜秒数；没有依据的估算标为「待核」。
