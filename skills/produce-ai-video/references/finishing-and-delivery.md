# 画面精修、色彩管理与目标交付

在实际素材进入合成/调色或准备母版时读取；只修提示词不启动本流程。已有目标规格先核其当前来源、适用范围和版本；网络短视频、电视平台与影院不共用默认交付规格。本文件不授权上传、付费或发布。

## 1. 锁定真实信号与监看

逐类素材记录实际分辨率、帧率/时基、编码与位深、色彩原色/传递特性/矩阵、全/限范围及来源。元数据未知或与显示不符标待核，不猜其是Log、RAW、HDR，也不把提示词里的IMAX/胶片品牌当真实采集属性。

选择适合输入与交付的工作空间、输入解释、监看与输出变换；可采用明确的Rec.709 SDR路线或工具支持且必要的色彩管理，不强制ACES。生成素材通常是已成像文件，不因套LUT获得原本不存在的动态范围。避免重复应用显示变换；保留未经破坏的源素材与可重建设置。

以已批准风格与实际基准画面作创意参考，以正确设置的监看和示波器检查信号。色域、亮度或显示条件不足时，不声称完成HDR母版或专业监看。跨设备抽查可发现问题，但不能代替目标环境校准与技术验收。

## 2. 镜头匹配与画面修复

先统一输入解释，再做曝光、白平衡、肤色、黑位和镜间匹配，最后实施全片Look及适用的颗粒/锐化/扩散。不要求日夜、闪回或主观画面同色；每种有意差异有故事依据。镜头匹配不能把锁定的光源、时间或材质改成另一场景。

实际瑕疵按来源分流：

| 问题 | 优先处理与边界 |
|---|---|
| 剪点暴露、余量不够 | 回剪辑或提出最小补镜，不拿变速吞台词 |
| 曝光/白平衡/黑位不一致 | 核输入与调色，保护肤色和高光，不靠全局滤镜掩盖 |
| 局部穿帮、边缘、文字、遮挡 | 有能力时做授权的修复/合成，核跟踪、遮挡、接触阴影、运动模糊与时序稳定；没有工具不假称已修 |
| 身份、关键动作或空间错误 | 回最早责任层；只有后期确能可信修复且在范围内才走合成，否则提重生成候选 |

修复记录绑定原素材、变更区域/帧段、派生文件与设置版本，实际回放检查新增缺陷；不能把失败参考图沿链用于重生成来冒充已批准资产。大改身份、构图或剧情需明确授权。

## 3. 交付配置

按目标建立本项目的 `delivery_profile`，记录要求来源/日期、容器与编码、分辨率/画幅、时基/帧率、位深、色彩与范围、声道布局、采样率/位深、响度测量方法与目标、真峰值上限、字幕/无障碍需求、文件命名与允许缺项。未选目标时只交声明过的候选规格，不冒称符合某平台。

- 生成来源不足时不能通过改标签冒充真HDR、原生高分辨率或更高位深的源细节。
- 目标要求时分别交干净画面母版、带字版、外挂字幕、音轨与多语言版本；没有字幕需求不强制烧录或产生字幕文件。
- IMF、DCP、5.1、Atmos、M&E等仅按真实目标与工具能力执行；不把有MP4或可播放预览当成上述交付已完成。
- 如需安全区、字幕可读性、闪烁风险、音频描述等无障碍检查，按目标规范与实际检查能力记录；未检查项显式待验证。

## 4. 母版、QC与归档

从同一已批准锁画版与最终混音生成母版，绑定时间线、素材、声音、字幕、调色/合成设置版本与哈希。机械QC、逐切点审阅、正常速度全片回放分别留证；`media_qc.py` 仅覆盖其实际报告的机械项，不检查完整色彩、编码规范、真峰值或平台合规。

检测失败/缺测量不能视为未发现问题；必检项未完成则该交付未完成。替代检查必须有真实测量、同版文件与授权复核记录，不能改写失败报告或放宽目标来通过。

归档保存可重建时间线、源素材清单、权利与批准记录、最终文件、技术报告和必要设置。检查清单与实际文件一致，必要时做恢复重建；磁盘空间、保留期限和备份目标按授权决定，不擅自删除源文件或上传私人素材。历史接受状态不因新导出自动继承。
