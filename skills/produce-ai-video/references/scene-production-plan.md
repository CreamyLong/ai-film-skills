# 以“场”为生产单元

镜头是生成单位，场才是体验单位。按镜头排产、按镜头写提示词，连续性就只能靠后期碰运气。本页给出可执行的场级计划与两个硬门。

## 1. 生产单元

| 层 | 单位 | 负责什么 | 不该在这里决定 |
|---|---|---|---|
| 集 | episode | 集间钩子、总时长、平台规格 | 单镜表演 |
| 场 | scene | 空间、时间、在场人物、环境声、场尾状态 | 具体机位 |
| 节拍 | beat | 一次攻防/信息变化/动作单元 | 景别 |
| 镜 | shot | 一个连续画面、一个说话人、一个动作单元 | 场与场之间的因果 |
| 生成段 | segment | 一次模型执行；可多段/loop | 独立镜头之间的连续性 |
| 声音单元 | ambience / spot / line | 底噪、动作声、台词 | 画面构图 |

**排产顺序必须是：场 → 节拍 → 镜 → 生成段。** 反过来先排镜头，就会得到“每镜都成立、连起来看不懂”。

## 2. 场级合同

每场先写清六项，再拆镜头：

1. **空间**：场景 ID、环境参考图、固定锚点（墙/门/窗/桌/灯位）。
2. **时间与光**：日/夜/黄昏、主光方向、色温范围。
3. **在场人物**：谁在、谁不在、谁在画外。
4. **环境声**：底噪来源、持续声、场尾是否延续到下一场。
5. **声音事件**：门、脚步、电话、画外台词；每条标注发生在哪个镜、画内还是画外。
6. **场尾状态**：人物位置、朝向、道具状态、谁知道什么；这是下一场的入场依据。

## 3. 镜头字段（缺一即 block）

| 字段 | 说明 |
|---|---|
| `scene` | 所属场 ID |
| `size` | 景别；对白特写不得标成 wide |
| `subject` | 画面主体 |
| `speaker` / `speaker_on_screen` | 说话人；画外必须为 false |
| `listener` / `listener_lips` | 画外说话时的在画听者；必须 `closed` |
| `env_ref` | 本场环境参考图；同场所有镜必须同一张 |
| `char_refs` | 在画角色参考；说话人在画时必须包含其 face |
| `entry` / `exit` | 首状态 / 尾状态；必须可被下一镜引用 |
| `sound_events` | 本镜发生的声音事件；画外台词必须登记 |
| `line` / `line_source` | 台词与来源（reference/locked/tts） |
| `transition_in` | 同镜续接 / 同场换视点 / 叙事跳跃 |

## 4. 两个硬门

### 渲前：`scripts/scene_plan_check.py`

检查场是否有环境声、镜头字段是否齐全、同场环境图是否一致、画外说话是否写明听者闭口、可见说话是否声明 reference/locked。缺项直接 block，不进入生成。

### 渲后：`scripts/dialogue_content_check.py`

拿 ASR 转写与 `line` 比对。中文按字符相似度：低于 0.6 判 blocker，0.6–0.9 判 review，高于 0.9 通过。专门抓“提示词写了台词、模型说成另一句”的情况。

## 5. 边界合同

每个切点写一行：

```text
边界 05→06｜同场换视点｜exit: 韩峥闭口等待｜entry: 韩峥转头看柜台｜
声场: 服务大厅底噪延续｜光: 同一顶光｜轴线: 韩在左、柜台在右
```

缺 `exit`/`entry` 的切点不允许进入剪辑。场与场之间允许空间变化，但必须写 `transition_in: 叙事跳跃` 与原因。

## 6. 与现有门的关系

- `scene_plan_check.py` 管“计划是否自洽”；
- `prompt_preflight` / `speech_route_check` 管“单条提示词是否可提交”；
- `dialogue_content_check.py` 管“生成出来的台词是不是这句”；
- `segment-seam-continuity.md` 与 `seam_review.py` 管“剪在一起是否顺”；
- `caption_preflight` / `audio_continuity_check` 管字幕与声音。

五层都过，才叫一场戏成立。
