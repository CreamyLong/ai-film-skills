# 音频路线 A/B：reference 与 locked

本记录是一次单镜对照，不是全模型基准。结论按可测证据分级，不能外推为“所有镜头 reference 更好”或“locked 更好”。

## 1. 测试设置

| 项 | 值 |
|---|---|
| 镜头 | EP008 镜 11，李承泽近景，90 帧 / 3.75 秒 |
| 台词 | “沈总生前有安排。” |
| 种子 | 1011 |
| 步数 | 4 |
| 画布 | 768×1344 / 24 fps |
| 参考图 | 人物 hero + face，`ref_image_size=max` |
| A：reference | `li_chengze.wav` 作为 `audioMode: reference`；提示词带引号台词，让 H3 自己生成语音 |
| B：locked | 同一句 TTS 补 0.15 秒前导静音并补到 3.75 秒，作为 `audioMode: locked`；提示词不写台词文本 |

两版使用同一提示词骨架、同一人物参考、同一 seed、同一步数；只改音频路线和必要的台词文本。

## 2. 可测结果

| 指标 | reference | locked |
|---|---|---|
| 视频 | 768×1344 / 24 fps / 3.75 s / 90 帧 | 同左 |
| 输出音频 | AAC 32 kHz 立体声 | AAC 44.1 kHz 单声道 |
| 均值 / 峰值 | −15.5 dB / −1.5 dB | −26.1 dB / −6.9 dB |
| 语音起始（−35 dB 静音检测） | 约 1.575 s | 约 0.538 s |
| 抽帧字幕 | 3 个采样帧无可见字幕 | 3 个采样帧无可见字幕 |
| 口型抽帧 | 语音起始后约 0.125 s 嘴部张开 | 语音起始后约 0.16 s 嘴部张开 |

**不能从这次测试证明的：**

- 没有 ASR/逐字听辨，不能证明 reference 生成的台词逐字正确；
- 只抽了 3 帧，不能证明整段无烧字幕；
- 只看嘴部开合，不能证明全程口型同步；
- 单镜、单角色、单 seed，不能外推到群戏、长台词、动作镜。

## 3. 观察与判断

### reference

- H3 自己生成语音，语气和停顿更可能跟画面表演一起长出来；
- 但语音起始明显晚于 locked（1.575 s vs 0.538 s），在短镜头里会压缩后半句或让台词晚进；
- 提示词里的台词文本是烧字幕的候选来源；本次 3 帧未烧，不等于整段不会烧；
- 同一角色轮换参考会漂移；必须每角色锁一条参考。

### locked

- 最终音轨就是 TTS 原波形，台词逐字、音色和时长可控；
- 音频作为零去噪 latent 条件驱动视频，口型跟随 TTS；
- 输出是 44.1 kHz 单声道且电平低（均值 −26.1 dB），组装时必须重采样到 48 kHz、转立体声并做电平归一；
- 表演上限由 TTS 决定：TTS 读得平，locked 视频也会平；
- 改一句台词必须重新生成 TTS 并重渲该镜，不能像 reference 那样只改提示词。

## 4. 选择规则

| 需求 | 选 |
|---|---|
| 台词逐字固定、要锁音色、不能烧字幕、能先做 TTS | `locked` |
| 让 H3 自己表演、台词允许模型自然发挥、没有先做 TTS | `reference` |
| 只有听者/背影/画外音，不需要说话正脸 | 无声 H3 + 后期 TTS/OS |
| 说话正脸 + 后期贴 TTS | 禁止；`speech_route_check.py` 直接阻断 |

**本次单镜结论：** 对 EP008 这种固定台词、单镜单说话人、需要逐字准确的项目，`locked` 比 `reference` 更合适。不是说 reference 质量更差，而是它把“台词是否逐字出现”交给了模型，无法满足当前合同。

## 5. 采用 locked 前的质量门

1. TTS 先定稿，按实际时长补前导/尾部静音到镜头长度；
2. 每条 locked WAV 做 48 kHz、双声道、电平归一后再送入 H3；
3. 提示词不写可读台词文本，只写表演、动作和说话状态；
4. 组装时该段不再加 `line`，否则重复对白；
5. 生成后抽帧查烧字幕，并做一次实际听辨/ASR 回读；
6. 多段执行时每段同文件、同 `trimStart`，否则插件报错。
