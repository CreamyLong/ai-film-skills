# 声音连续性：切点不能换房间

用于对白密集、逐镜独立生成的 AI 剧集。问题不是“某一句不好听”，而是相邻镜头的底噪、语速和响度各成一个房间，硬切时观众听到的是“换台”。

## 1. 先量，不靠耳朵猜

对每个镜头测三项：

| 指标 | 命令 | 用途 |
|---|---|---|
| 平均电平 | `ffmpeg -i shot.mp4 -af volumedetect -f null -` | 找 ±6 dB 以上的镜头差 |
| 切点前后 350 ms RMS | 解码为单声道后按窗计算 | 找“前一镜很静、后一镜很响”的跳变 |
| 过零率/频谱重心 | 可用 `astats` 或简单 ZCR 近似 | 判断是不是底噪质地换了 |

判定参考：

- 同一场对白镜之间，切点响度差 **≤3 dB**；超过 6 dB 必须处理。
- 单集内对白镜平均电平极差 **≤4 dB**；超过 6 dB 先做镜头增益对齐。
- 切点前后底噪质地明显不同（ZCR/高频能量突变）时，只调增益不够，必须铺房间底噪。

## 2. 四层修复，从便宜到贵

### 第 1 层：逐镜增益对齐

按镜头内容分目标：对白镜对齐到同一对话电平（如平均 -19 dB），环境/反应镜对齐到更低的环境电平（如 -30 dB）。用测得值算增益，不用统一 `volume=0.9`。

```bash
ffmpeg -i shot.mp4 -af "volume=+5.2dB,afade=t=in:d=0.02,afade=t=out:st=3.73:d=0.02" ...
```

每个镜头首尾各 20 ms 淡入淡出，消除硬切爆音；不改变画面时长。

### 第 2 层：一条贯穿全集的环境底

从**无台词**镜头取 3 秒底噪，循环铺满全集，压在对白下面（约比对白低 18–24 dB）。切点处观众的耳朵有连续参照，不会觉得“换房间”。

底噪源必须是安静镜，不能拿有台词的镜头当 `tone_from`：那会把上一句台词以半音量重复一遍，形成“鬼声”。静帧尤其容易犯这个错。

### 第 3 层：切点微交叉

同一场内硬切保留画面硬切，音频在切点做 20–50 ms 等功率交叉；场与场之间用 0.3 s 淡黑时，音频同步 0.3 s 交叉。交叉会缩短总时长，必须与视频淡黑长度一致，不能各算各的。

### 第 4 层：镜头内的问题单独修

- 某镜底噪明显更响：先降该镜非对白段，或整镜降 2–3 dB 后用对白补偿。
- 某镜语速/音色漂移：换音色锚或重生成，不靠后期 EQ 硬拉。
- 静帧卡：底噪取自同场安静镜；没有就只留全集底，不要借用对白镜。

## 3. 交付前检查

1. 跑 `scripts/audio_continuity_check.py`，看逐镜电平表和切点跳变。
2. 静帧的 `tone_from` 必须指向无对白镜；指向对白镜直接判 blocker。
3. 抽听三个最差的切点，确认没有“鬼声”、爆音、明显响度台阶。
4. 整集响度按平台目标做一次线性归一（如 -16 LUFS 流媒体），不要逐镜再压。

## 4. 工具与外部参考

- `ffmpeg-normalize`（slhck）：支持 EBU R128 / RMS / peak 批量归一，可保留视频流；适合做整集终混，不解决切点底噪。
- FFmpeg `loudnorm`、`ebur128`、`volumedetect`、`acrossfade`、`amix`：逐镜测量与拼接的基础件。
- 公开仓库里没有成熟的“房间底噪自动匹配”工具；可复用的是响度归一工具，切点连续性仍要靠“底噪床 + 增益对齐 + 微交叉”这套工艺。

## 5. 禁止

- 用统一 `volume=0.9` 代替逐镜测量。
- 把有对白的镜头设为静帧/空镜的 `tone_from`。
- 只做视频淡黑、音频不跟着淡化。
- 用整集压缩器掩盖镜头间 ±10 dB 的落差；压缩后对白会 pumping，底噪反而更明显。
