# H3 台词提交前修正门

## 目的

在 H3 视频生成**之前**检查实际提交的台词写法。它只校验对白格式与说话人绑定，不判断剧本是否写得好、不确认音色是否合适、不替代实际听审或 ASR 回读。

本门解决的问题：H3 的台词标记格式被写错时，模型会把台词当旁白或普通引号，输出“像说话但听不清”的噪声，或者把表演说明念出来。提示词结构检查通过，不代表台词会被正确念出。

外部参考：HelloGen 的 MiniMax H3 gibberish-speech 修复文章（2026-11-16 查阅）。本文只吸收其公开规则，不复制其页面正文。

## 官方写法

每条台词按以下顺序写，全部放在 `<d>` 外，只有逐字台词在 `<d>` 内：

```text
<声音描述> <角色名> (S1) says: <d>[中文] 逐字台词。</d>
```

要求：

- 先写年龄、音高、音色、语速、口音等声音描述；
- 再写说话人 ID `(S1)`、`(S2)`；多人同时发声写 `(S1,S2)`；
- 写清发声方式：`says`、`asks`、`answers`、`whispers`、`shouts` 等；
- `<d>` 内先写语言标签，再写逐字原文：`<d>[中文] …</d>`；
- `<d>` 内保留原文语言、标点和用词，不翻译、不改写；
- 句末用 `.` `?` `!` 收尾；不要用省略号 `……` 或 `...`；
- 表演、动作、镜头、呼吸说明全部放在 `</d>` 外；
- 画外音写 `says in an off-screen voiceover`，并说明画内嘴唇保持闭合；
- 台词短于视频时长时，补沉默动作、环境声或明确写“无对白”，不要让模型自行加词。

## 七类常见故障

| 症状 | 原因 | 修正 |
|---|---|---|
| 有声但听不清词 | 台词写成旁白或普通引号 | 用 `<d>[语言] 原文</d>` |
| 开头约 0.5 秒噪声 | 种子或参考音问题 | 换种子；参考音约 4 秒；句末加句号；补环境声 |
| 台词结束后继续编词 | 台词明显短于视频 | 增加台词、沉默动作或环境声，让时间被内容填满 |
| 表演说明被念出来 | 说明写在 `</d>` 内或紧跟台词 | 把声音/动作说明移到 `says` 前或 `</d>` 后 |
| 台词分给错的人 | 没有说话人 ID，或同镜多人无绑定 | 固定 `(S1)/(S2)`，一句一说话人，优先一镜一人 |
| 口型对不上 | 正面说话但声音路线不匹配 | 正面对白用 H3 原生/参考音色或 locked audio；后期配音只用于 OS/背影 |
| 台词被改写 | 没有逐字保留，或模型自行翻译 | 原文照写，语言标签匹配；不要写“翻译成…” |

## 与现有检查的关系

提交前顺序：

1. `context_ir_check.py` 或 `h3_base_check.py` 查 H3 结构；
2. `dialogue_preflight.py` 查台词格式、语言标签、说话人 ID、`says`、省略号、多人同镜；
3. `timeline_plan_check.py` 查时间线与音频路由；
4. `prompt_preflight.py` / `submission_gateway.py` 查实际提交记录、资产、哈希与授权；
5. 生成后实际听审；有 ASR 时做逐句回读，没有时标 `未验证`。

任一门 `BLOCK` 都不得提交。`REVIEW_REQUIRED` 不是通过；必须逐项核对并记录证据。

本门不检查：

- 台词是否符合剧本语义；
- 台词是否与演员口型、音色或表演匹配；
- 是否存在同音字误读；
- 生成音频是否真的说了这些字。

## 修复流程

1. 找到出问题的具体 `<d>` 片段，不改其他镜头。
2. 重写为 `声音描述 + (Sx) + says: + <d>[语言] 原文</d>`。
3. 删除台词内省略号和表演说明。
4. 一镜多人时优先拆成单人镜头；不能拆时保留固定 ID 并单独听审。
5. 台词短于镜头时补沉默动作或环境声。
6. 只改一个变量后重跑本门；仍失败再换种子或参考音，不同时改多项。
7. 生成后逐句回读/听审；没有工具时明确写 `未验证`，不能凭“听起来像”通过。

## 运行

```text
python scripts/dialogue_preflight.py --input <actual-prompt.txt>
```

输出 JSON：

- `PASS`：未发现格式问题；不证明语义、音色或成片合格；
- `REVIEW_REQUIRED`：有需人工确认项，例如一镜多人或缺少声音描述；
- `BLOCK`：必须修正后才能提交。

脚本不联网、不生成提示词、不修改输入、不执行生成。
