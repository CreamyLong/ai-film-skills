# 从用户目标选择创作路径

本文件是任务分解与验收合同，不是批量提示词模板。所有提示词由负责角色逐项理解、撰写和复核；总控只安排必要阶段。按用户终点停止：咨询/方案、剧本、分镜、提示词、试样或成片不能混为一类授权。

## 1. 共用入口

判断用户要改变或交付什么，读取现有材料并复用批准决定，再选择当前路径。类型可混合：有故事的产品广告仍需产品保真，带演唱的剧情MV仍需音乐时间线。不要默认所有输入都要编剧情、人物或对白。

| 输入 | 先做什么 | 不能假装已经完成 |
|---|---|---|
| 一句话/故事 | DIRECTOR 明确受众、作品承诺、形态、行动因果及开放选择 | 一句话不是已批准剧本或无限媒体预算 |
| 参考视频 | 用真实读取能力分析画面/剪辑/声音，区分迁移的风格和不复用的内容 | 标题、缩略图或文字介绍不是看过视频 |
| 音乐/歌词 | VIDEO_PRODUCTION 的可用音频分析能力读取实际音乐；DIRECTOR 形成视觉概念 | 没有听到不编造BPM、拍点或歌曲段落 |
| 产品图/资料 | PROP_ASSET 与 PRODUCTION_CONTROL 固定产品真值、展示需求与可用来源 | 单张图不能证明不可见结构、尺寸或性能 |

商业目标与受众判断由现有具备能力的角色承担；不要假称已安装广告策略师、音乐分析器或产品工程验证器。需要市场研究才分派 MARKET_RESEARCH，不为简单创意默认开展全市场报告。知识写入、网页和预演只在明确需要且已授权时分派。

## 2. 一句话到完整短剧

**路径：** DIRECTOR 形成可读故事/剧本和导演意图 → 必要视觉基准确认 → CHARACTER_ASSET / SCENE_ASSET / PROP_ASSET / SOUND_ASSET → STORYBOARD 可剪分镜/时序 → VIDEO_PRODUCTION 提示词、生成、选条、剪辑、声音、后期、完整回放与修复。PRODUCTION_CONTROL 跨阶段核版本、状态、预算和交接；多集增加整季/分集作用与跨集历史。

**前置：**明确作品形态、时长/范围和用户锁；开放设计主动提出有依据的方案。人物跨镜准备四张纯白背景图（全身主图、面部特写、表情九宫格，以及含正面、90°侧面、背面全身和六格头部多角度的角色表），同角色服装/伤势等长期变化使用审过的状态变体。音色和人物映射独立管理，模型每次引用实际基准而非依赖记忆。

**验收：**行动、人物知情、策略与关系变化可理解；画面和实际语音兑现剧本；跨镜/跨集身份、状态与声场可信；整片正常速度可看、结尾兑现。单镜漂亮、字幕齐全或结构检查通过不等于整剧通过。

**范围：**“先写剧本”到可读剧本结束；“做成片”在已确认权限与费用内包含必要中间阶段，但不取消各层真实批准门。欠预算或授权时先交已完成部分。

## 3. 参考视频到TVC / 宣传片

**先定传播任务：**品牌/主体、目标受众、传播目的、一个主要印象或卖点、时长/渠道、行动指引及禁改事实。区分销售广告、品牌形象与机构宣传，不能一律强加剧情或购买CTA。产品性能/数据未经依据不得编造。

**参考拆解：**实际查看选定片段，记录有依据的时间范围、景别/机位、摄影运动、切点/节奏、光色/材质、表演、图形/字幕和声音作用。区分风格借鉴、镜头机制迁移、原内容复用；只借风格不能默认复制音乐、演员、商标或剧情。未知拍摄参数保留为推断，不冒充原片事实。

**路径：** PRODUCTION_CONTROL 提炼brief/事实/权利 → DIRECTOR 提出适合本品牌的创意命题与可见方案 → 适用资产/视觉基准 → STORYBOARD 设计信息、产品与品牌显露 → VIDEO_PRODUCTION 执行、剪辑、声音、图形/落版与交付。品牌方向、主张和关键产品真值需按当前权限确认，不让用户逐镜选焦段。

**验收：**观众能理解“是谁、表达什么、为什么与自己有关”；品牌/产品和必要落版可读且正确；新主体真正适配所借视觉关系，不是原片只换名称。商业信息、文字/Logo保真、音乐和素材使用范围单独审核。

**回退：**参考无法读取则停在候选方向，说明缺视频；受限制的功能演示回事实层。需要准确标识/文字时优先考虑真实素材或后期合成，不要求生成模型凭空拼写正确。

## 4. 音乐驱动MV

**音乐先行：**确认本次使用的真实音乐版本、是否可剪/改速、歌词语言与授权。实际听取并按能力查看波形/节拍，记录乐句、段落、情绪/能量、歌词事件和候选视觉节点；BPM或自动检测只是辅助，实听核拍点/重拍/变拍和自由速度，不虚构整齐网格。

**选择模式：**演唱/演奏、剧情、视觉母题、舞蹈或混合。DIRECTOR 让视觉随音乐发展、重复与变奏，不机械逐句画歌词，也不要求每个鼓点切镜；无叙事MV不硬造对白或因果场景。

**路径：**音乐读取与结构图 → 视觉概念与段落发展 → 必要人物/服装/空间/产品/声音资产 → STORYBOARD 音乐时间线上的动作与切点 → VIDEO_PRODUCTION 生成、表演同步、剪辑、声音保全和全曲回放。

原曲若作为最终音轨，保持版本和时间基准，原生视频配乐不得重复叠加或替换原唱；音色参考不等于复制歌曲。需要对口型时落实实际演唱段、歌词、音节、演唱者和工具能力；没有可靠口型路线就提出非演唱画面等候选，不能冒称同步完成。

**验收：**歌曲结构与视觉发展相互成立，主题有变化而非随机漂亮镜头；歌词/演唱需要时同步可核；不为拼素材擅剪歌曲；最终实际音轨、片长与结尾完整。未读音乐只可交待验证概念，不交伪时间码。

## 5. 产品展示片

**产品真值：**以用户实际产品资料确定型号、轮廓比例、材质/颜色、结构/接口、标签/Logo、功能和禁改项；不可见面、精确尺寸与内部构造未知时询问或限制镜头，不凭空补齐。区分可重新设计的概念产品与必须忠实呈现的在售商品。

**展示规划：**按传播目标选择整体辨识、核心特征、使用过程、关键细节、材质、尺度与落版；每个镜头回答一个真实展示问题，不让镜头炫技遮住产品。视图按需求准备，不把多视图机械规定为固定格数。

**路径：**产品输入/真值与卖点 → PROP_ASSET 可复用产品基准与必要视图，涉及人物/空间才补相应资产 → DIRECTOR / STORYBOARD 展示顺序、照明、摄影和操作 → VIDEO_PRODUCTION 选择真实素材/抠图合成/可控渲染/生成环境或组合路线，再制作与质检。只有工具真实支持且素材授权时采用该路线。

**验收：**跨镜仍是同一产品，关键几何/部件数量/标签/材质正确，操作和声效不暗示未证实性能；小字和Logo按实际图或后期核对。不能用道具设计自由擅改真实产品，也不以“电影感”抵销商业保真失败。

## 6. 交接与验证

每条路径按 `references/orchestration-loop.md` 的任务/证据状态推进，复用同一项目记录。无工具/无授权则交具体缺口和当前已完成产物；不能退化成让用户从一长串技能中自己选择，也不能假装已有自动执行引擎。

分别验证这四种任务是否正确发现前置需求、选路线、保全资产/声音/产品、逐项写提示词、检查实际结果并修复。合同覆盖、打包与文本回归不等于这四种完整成片已被真实用户接受。
