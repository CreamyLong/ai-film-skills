# 创作总控：任务、交接与恢复

总控承担进度和交接责任，不让用户先学会选择技能。宿主负责提供实际可用的角色与工具调用；本包不内置模型、账户、播放器、调度引擎或其他技能源码。只能规划时就明确交任务包；能执行且已获授权时则持续推进，不把计划表当最终作品。

## 1. 范围与状态

从现有项目记录恢复作品身份、源材料与版本、用户要求的终点、锁定事实、批准范围、预算/上传/声音权利、已完成阶段及待办。只有聊天咨询而没有项目目录时可以交文本方案，不创建伪项目或声称已经持久化。

把本轮范围与故事锁分开。“先看方案”只限定当前执行，不成为永久故事事实；“继续”只能承接此前明确阶段与授权，不能升级媒体或费用权限。

在既有项目记录中维护必要的 `orchestration` 信息，不创建第二份剧情或资产真值：

| 项 | 最小内容 |
|---|---|
| 请求 | 项目、任务类型、当前目标、交付终点、源版本、锁定内容与批准范围 |
| 能力 | 实际可读媒体、可用角色、生成/声音/剪辑/回放工具及已知限制；未检测的保持未知 |
| 任务 | 稳定ID、负责角色、输入版本/哈希、依赖、输出、验收标准、费用上界与授权来源 |
| 进度 | 状态、真实调用/返回、当前产物、审核证据、缺口与下一动作 |

普通创作选择由负责角色提出并决定开放项，不把焦段、机位或每个镜头都变成用户问卷。会改变核心意义、品牌/产品事实、权利、发布、费用或锁定结构的缺口先确认。已有批准直接复用，不能自己把候选升级成用户批准。

## 2. 前置能力与资产检查

先验证本轮确实能读取输入。看不到视频就不能声称完成参考片拆解；没听到音乐就不能编造节拍和情绪时间码。区分工具可用、请求已提交、媒体已返回、实际已查看四种事实。

按源材料、设计与投送需求三次核对人物、空间、产品/道具、声音和变体；录入“完整”不证明找全。人物身份需要跨镜保持时安排完整五视图（正面、3/4、侧面、背面全身加中景）、可见身份标记的特写、按戏份需要的表情母版及适用状态资产；场景准备能解释所需机位的空间依据；产品视图按保真和展示需求选取，不给所有物件机械套人物五视图。

先建立并按负责阶段要求确认项目视觉基准，再生产具体资产；缺批准则停在风格提案/已授权试样，独立剧本工作可以继续。参考和身份资产审核后逐镜绑定真实文件与版本，不以文件名、同一资产ID或“一致”二字代替实际匹配。

有对白/演唱/旁白时区分角色与说话人，安排音色基准、权利、声线与表演要求；原生音频路线核实际参考支持与绑定，不支持或不稳定时提出授权外配/后期路线。没有对白、人物或场景需求时不增加无用资产。

## 3. 分派与推进

1. 在本轮已发现的宿主能力中解析角色；不硬编码兄弟技能路径，不读取共享私有目录，也不假定能自动安装依赖或启用子代理。
2. 任务包写清目标、输入/版本、允许变更、保持项、依赖、预期产物、质量标准、预算/权限、回退层与完成证据。只读诊断不能变成改稿，创意采用不等于生成授权。
3. 在前置已满足时，通过宿主真实支持的机制启动负责角色；已授权且工具可用就继续，不让用户逐阶段手动选技能。独立分支可并行，但共享已锁决定，未审上游不能偷偷被下游消费。
4. 若角色未安装或宿主不能交接，报告具体缺失角色/能力与可直接执行的任务包。能继续的无依赖文本分支照常推进；不制造调用日志、素材路径或“已完成”状态。
5. 收到结果后核实际文件/正文、版本、适用范围、审核结果和费用/请求状态。要求看片/试听的内容必须交有真实能力与权限的复核者，不能以报告文本当作亲眼看到。
6. 合格且依赖有效才释放下游；不合格回最早责任层修复，只有必要范围返工。用户锁定与可执行性冲突时交具体选项，不擅改台词、镜序或产品形制。

## 4. 状态与停止条件

任务使用 `pending`、`ready`、`running`、`review_required`、`accepted`、`blocked`、`stale`。`accepted` 只表示该任务范围获真实相应审核，不能替代用户对整片的接受。发出调用不算完成；产物存在进入待审；审核者/权限/证据不足仍是待审或阻断。

输入或批准版本变化时把受影响任务置 `stale`，保留无影响分支，更新变更依据后再审。恢复先核当前文件与依赖，不直接信旧聊天或旧完成标签。

提交结果未知时先对账，禁止重复发送来试探；新尝试先核剩余预算与授权。明确每轮尝试/返工边界；费用到线、反复失败且无新修复依据、工具缺失、权利或关键证据不足时，停止对应动作并列出可继续范围。不得无限重抽或悄悄降低验收标准。

## 5. 最终返回

已完成时先交用户要求的剧本、方案、分镜、提示词或真实成片，再给精简验证状态和残留问题；不展示不必要的内部编号/哈希。过程记录留在项目中，不用整套生产表替代作品。

受阻时交实际已完成产物、未完成范围、唯一/关键缺口、下一步和所需决定；没有真实媒体就不能把提示词/预演/联系表当成片。分别记录结构检查、实际执行、完整回放和用户接受；本合同不证明已具备稳定一键生成复杂成片的能力。
