# 生产就绪门｜Production readiness gate

## 目的

把“项目看起来可以生成”变成可检查的阻断条件。总控在分派图片、视频、音频或配音任务前读取项目级 `项目开发/production-gate.json`；文件不存在、字段不完整或门未通过，就不能把任务送进生成，只能先补对应资产、分镜、声音或授权。

本门管的是**进入媒体生产前的就绪证据**，不评价创意质量，也不替代逐片验收、批量前质量门或用户对实际成片的接受。

## 文件位置

默认放在项目状态目录：

```text
<project>/项目开发/production-gate.json
```

项目使用其他状态目录时，放在与剧本、分集地图同一项目状态目录，并在任务包里写明实际路径。不要在多个位置维护互相冲突的第二份真值。

模板位置：`assets/production-gate.json`。

## 门状态

| `gate_status` | 允许做什么 | 不能声称什么 |
|---|---|---|
| `ready_for_text` | 剧本、分镜、提示词或其他文本交付 | 不能生成或声称已有媒体、配音、成片 |
| `ready_for_generation` | 按已批准范围分派图片、视频、音频或配音任务 | 不能替代实际播放检查、用户接受或最终交付 |
| `blocked` | 只能补缺口、做文本、等授权 | 不能分派受影响媒体生成，不能把计划当完成 |

任一 required check 为 `pending` 或 `fail`，门就是 `blocked`。缺文件等同于 `blocked`，不是“默认放行”。

`not_applicable` 只能用于本任务确实不需要的检查，并写明理由；不能用它绕过声音、资产、费用或授权。

## 按终点检查

| 终点 | 至少需要通过的检查 |
|---|---|
| 文本 / 大纲 / 诊断 | `accepted_brief`；涉及节奏时 `accepted_rhythm_profile` |
| 分镜 / shot list / 提示词文本 | 文本检查 + 对应分镜或提示词产物；仍不授权媒体生成 |
| 静帧 / 关键帧 | 分镜或镜头依据、适用人物/场景/道具资产、`model_route`、`cost_preview_confirmed`、`generation_authorized` |
| 单镜视频 / 多镜视频 | 静帧所需项 + 镜头表/分镜 + 连续性锁 + 适用声音资产；有对白时 `voice_samples_approved` |
| 配音 / 对白驱动 | `sound_assets`、`voice_samples_approved`、`dubbing_authorized`；需要口型时另核锁定音轨与视频路线 |
| 成片 / 交付 | 以上适用项 + 实际播放检查、混音/字幕检查、用户接受记录 |

检查项按本次终点取适用集，不为填满模板制造不需要的资产；但“适用”必须由实际画面、台词和交付目标解释。

## 检查状态与证据

每个 check 使用：

```json
{"status": "pass", "evidence": ["项目开发/分镜/EP001.md"]}
```

- `pass`：有真实产物、版本/哈希或审核记录可指向；资产合同还要有批准状态。
- `pending`：尚未完成或尚未被负责角色复核。
- `fail`：已检查但不满足，必须回到归属层修复。
- `not_applicable`：本任务确实不需要，并写明原因。

证据路径必须是项目内可解析的相对路径；不写私人绝对路径、凭证、客户资料或未授权素材。用户批准、费用授权、声音权利与平台执行权限各自独立，不能用“文件存在”代替。

## 归属

| 检查/缺口 | 负责角色 |
|---|---|
| brief、节奏档案、分集状态 | DIRECTOR / PRODUCTION_CONTROL |
| 分镜、镜头表、连续性锁 | STORYBOARD |
| 人物、场景、道具资产 | CHARACTER_ASSET / SCENE_ASSET / PROP_ASSET |
| 音色、样音、环境声、标志音效、音乐主题 | SOUND_ASSET |
| 模型路线、参数、回退顺序 | PRODUCTION_CONTROL（调用模型选型能力） |
| 费用预览、生成授权、发布权限 | 用户 / PRODUCTION_CONTROL 记录 |
| 实际生成与播放检查 | VIDEO_PRODUCTION |

总控只维护门的读取、阻断和交接；不替专业角色宣布资产已批准，也不替用户给出费用或发布授权。

## 与其他门的关系

1. **本门先执行**：没有 `ready_for_generation`，不进入批量生成，也不进入批量前质量门。
2. **Sound asset gate 是本门的子集**：有对白时，声音合同与用户审听通过是必要项。
3. **批量前质量门不等于本门**：`pregeneration-quality-gate.md` 验证提示词流程与画面质量；它不能补人物资产、场景资产、费用授权或用户批准。
4. **本门不等于成片验收**：通过本门只表示可以按范围执行，不证明实际片段、完整播放或用户接受通过。

## 更新规则

- 每次任务开始、资产版本变化、授权变化或回退后重读门文件。
- 只更新受影响 check；不要把旧 `pass` 无证据地复制到新版本。
- 资产、分镜、声音或授权版本变化时，把下游 check 置回 `pending` 或 `stale`，再核对。
- 脚本只可校验字段、路径和状态一致性；不得生成、补写或伪造证据正文。

## 失败时怎么返回

门失败时返回：已完成的文本、未通过的 checks、最早负责角色、下一项可执行任务、所需用户决定。禁止用“再生成一次”绕过缺失资产、分镜、声音或授权。
