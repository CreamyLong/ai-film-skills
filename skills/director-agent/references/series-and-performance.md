# 长篇、整季叙事与人物表演

用于长片、多集剧本、跨场人物弧、选角/试声方案或表演诊断。局部改句只处理受影响的关系和状态，不扩成全季开发。这里形成创作决定与可核对交接，不授权生图、配音、视频或付费；所有提示词仍逐项撰写复核，禁止脚本批量生成。

## 1. 确认作品承诺与结构

先选作品形态：长片、连续剧、单元剧、限定剧或混合。写清观众跟随谁、期待哪种经历、核心戏剧问题及其答案的代价；风格与节奏不由平台长度或“爆款模板”代替。已有批准方案直接继承，未定结局可标候选，不冒充锁定。

- 长片：从人物的初始策略到失效、调整与最终选择建立完整因果脊柱；段落推进、支线和主题意象改变主线的选择与结果，不硬套分钟配额。
- 连续剧：确定全季不可逆变化、阶段性问题与终局兑现；留续季空间不能取消本季已承诺的满足。
- 单元剧：本集局部问题能获得相应解决，持续关系/世界线按需要推进；不强制每集 cliffhanger。
- 限定剧：核对季终是否兑现开篇核心承诺，避免靠季外解释、突然到来的事实或下一季补完。

## 2. 整季开发顺序

1. **整季故事论证**：用可复述的行动因果说明起因、策略、压力变化、不可逆选择、代价与结束状态。悬疑先核真相能否解释已有事实，再设计揭示顺序。
2. **人物关系弧**：主配角各有独立欲望、保护对象、误判与代价；记录关系何时因谁的行动变化，不把配角当提示器或剧情开关。
3. **多线交织图**：按当前作品标主线、次线或群像线，说明相遇时如何互相改变条件、信息或选择。不是每集必须等量分配，也不为凑线索另加角色。
4. **分集作用表**：每集写局部问题/满足、推进的季问题、人物选择与关系变化、引入/兑现、结束状态和下一集的必要性。相邻集不重复同一冲突再把人物归零。
5. **中段压力检查**：追问新集增加的是新条件/代价，还是仅延迟答案；主角策略必须能发展、犯错和调整，不靠反复误会拖长。
6. **删除/换序测试**：删掉或调换一集/一段，明确会破坏哪条因果、人物变化或观众认知。可独立换序的单元不硬判错，按作品形态检查。
7. **兑现审阅**：逐条核对开篇承诺与伏笔的兑现、改义或明确保留，不把“线已关闭”当作情感满足。

精简交接采用现有项目记录：`season_intent`、`character_arcs`、`relationship_turns`、`episode_functions`、`reveal_map`、`unresolved_risks`。记录决定、原文依据、范围与版本，不要求额外平行台账，也不要求用户填表。

## 3. 三种时间与知情控制

故事事件发生时间、观众呈现顺序、素材生产顺序分别记录。每个重要秘密分清事实真相、各角色所知/误信、观众所知；知情变化有获得方式、发生场次与来源。闪回、梦境、不可靠叙述和重播标清语境，不把历史状态覆盖当前世界，也不提前泄露观众不应知道的事实。

改稿时先指出哪项事实、弧线、关系或揭示变化，列受影响的前后场/集与生产交接；保留未受影响决定。修订需与当前批准版相对照，下游已制作内容不因文字更新自动视为更新。

## 4. 角色表演与试读

人物资产保证身份，表演方案负责“这个人怎样活着”。从原文和人物经历推导，不机械规定所有人有小动作、停顿或情绪高潮。

| 层次 | 需要决定与核对的内容 |
|---|---|
| 角色基线 | 注意什么、怎样保护自己、说话节奏/词汇、身体习惯、与不同对象的距离和边界；区分稳定特征与本场状态 |
| 场景表演 | 进入时知道什么、想改变谁、使用什么策略、对方做什么后改策略、结束时哪项关系/信念已变化 |
| 听者与沉默 | 听见/没听见、误解、反应延迟、压住冲动、拒答或转移；不要求每句都有可见反应或反应镜 |
| 声音身份 | 语言/口音、音域与发声习惯、年龄/身体状态；场景情绪改变不能导致换人，参考与克隆需单独授权 |
| 跨场承接 | 伤势、疲劳、呼吸、情绪余波、掩饰和关系压力按故事时间延续，明确何事使其变化 |

若任务包含选角/试声，先给角色可演的试段与判断标准；在相同事实、台词和时窗下比较不同表演，不以容貌、声线华丽或情绪更大自动胜出。实际试读须有相应工具和授权；文字朗读建议不记为已听到。

对关键对白场景，至少核对说者目的、听者理解、策略转折及实际可说时长。可在重要开放位置比较两种表演意图，不逐句强做多版；已锁定台词不改字。非人主体、无对白、无人物或纯静物任务只执行适用部分。

## 5. 审阅与返回

- 初读者不看设计说明，能复述主要行动、区分人物，并指出自然或刻意的台词；无独立能力时标 `SELF-AUDIT ONLY`。
- 整季结构通过不等于好看；分别记录逻辑、人物、节奏、读者反应和用户接受。
- 片段表演不真先查目标、关系和听者反应，再改对白或动作；不以加表情、镜头或细节掩盖人物缺口。
- 交付当前请求的剧本/方案及必要交接，不用一堆字段替代正文。缺试读、独立阅读或真实视频证据时保留 `未完成/待验证` 的相应范围。
