# 三集一回合、回合尾与 setup→payoff 台账

用于系列开发、分集地图和已有多集剧本的返修。它把“这一集好看”提升为“连续几集扣得住”：每个回合要有进入问题、升级、反转、代价和出去的钩子；每个伏笔要有埋设、知情状态和兑现位置。方法思路参考 short-drama-factory 的“情绪契约单元链/三集一回合”和 OnlyShot 的 `setup→payoff`，本文按本包的因果与分级规则重写，不复制其正文。

## 1. 回合不是三集配额

**默认诊断单位是 2–4 集一个回合**，三集只是常见长度，不是硬模板。两集能完成就不要注水成三集；四集才够完成证据阶梯也不要硬压。

一个合格回合至少完成：

| 要素 | 要回答的问题 |
|---|---|
| 进入问题 | 这个回合开始时，谁想得到什么，为什么现在必须行动？ |
| 压力升级 | 对手做了什么反制，使原来的办法失效？ |
| 证据/关系阶梯 | 每一集新增了什么事实、代价或权限变化？ |
| 反转 | 哪一步让观众重新理解前面的证据或人物？ |
| 代价 | 主角为这次推进失去了什么，且不可无代价复原？ |
| 回合尾 | 本回合的局部结果是什么，同时留下什么必须进入下一回合的问题？ |

**回合尾不是“再抛一个 unrelated 事件”。** 它必须从本回合已经产生的状态长出来：新证据指向谁、谁知道了什么、谁被迫做出选择、哪条退路被堵死。

## 2. 每集都要有自己的结果

- 本集结果必须能追溯到**本集主视角人物的选择**：部分成功但暴露弱点、失败但拿到新证据、误以为成功而代价启动、主动放弃原目标、对手封死路径迫使换策。
- 不许用“这集只是过渡”解释没有结果；过渡集也要改变一个关系、权限、知情或代价。
- 不许连续三集用同一种回合尾（都是“有人推门”“电话响起”“发现尸体”）。重复会提前暴露公式。
- 观众已经知道的事实，不要用两集反复“证明”。第二次证明必须带来新代价或新误判，否则删。

## 3. 因果链写法

每个关键拍用以下连接词自检：

- **because**：因为上一拍的结果，所以这一拍必须发生；
- **but**：人物采取了行动，但对手/环境给出反制；
- **therefore**：因此人物改变策略，产生下一拍。

如果两拍只能写成“and then”“过了一段时间”“突然有人来”，因果链不成立。补一个真实的因果条件，或删掉这一拍。

**本集结果 → 下一集进入状态**必须可交接：伤势、持物、知情、关系、地点、承诺至少有一项发生不可忽略的变化。

## 4. setup→payoff 台账

每个伏笔至少登记：

```json
{
  "setup_id": "S-009-01",
  "setup_episode": 9,
  "object_or_info": "墙上平面图的三个红点：桥、档案室、刑侦支队",
  "who_knows": ["韩峥", "沈远"],
  "audience_knows": true,
  "payoff_episode": 15,
  "payoff_action": "第二次坠江发生在桥；档案室与支队内应同时被点名",
  "cost": "沈国栋为救沈远暴露在公众面前",
  "status": "planted"
}
```

规则：

- 每个 setup 必须有 payoff，或明确标为 `open` 并说明是否留给季终/续季；不能无限埋不收。
- 不要把所有 payoff 堆在最后三集；中段至少兑现一部分，让观众感到“埋了会响”。
- payoff 必须改变局面，不只是“解释前面”。解释型回收最多承担一次，第二次要付代价。
- 人物知道的与观众知道的要分开记；角色不该知道自己没在场的信息。
- 道具型伏笔同时记“在谁手里、是否被看见、是否被误认”；否则后面兑现时容易变成巧合。

## 5. 与 20 集项目的映射

20 集×约 2 分钟可以按 5–7 个回合组织，不必套 60–100 集的付费卡点表：

- 每回合 2–4 集；
- 每集有局部结果与出去的钩子；
- 每 2 个回合至少兑现一次中段伏笔；
- 最后 2–3 集集中兑现主线，但不把全部配角线都压到结局；
- 不设固定“第 8/12/26 集付费点”；如平台有卡点要求，由创作者指定位置，本文件不默认。

## 6. 返修顺序

1. 先画回合表：每回合的进入问题、升级、反转、代价、回合尾。
2. 再查每集结果是否由主视角选择造成。
3. 再查 setup→payoff 台账，找无主伏笔和无铺垫兑现。
4. 最后才改台词和场面；不要用加旁白、加反转或加新人物掩盖因果缺口。

## 7. 验收

- 每个回合能一句话说清“谁因为什么做了什么，付出什么代价，留下什么问题”。
- 连续三集不是同一种回合尾；不存在连续两集重复证明同一事实。
- 所有已埋伏笔有兑现或明确 `open` 标记；没有“最后一集清单式回收”。
- 每集结果能追溯到本集选择，下一集进入状态与上一集退出状态一致。
- 以上不成立时，回开发/分集层修，不在写作层用漂亮台词补洞。
