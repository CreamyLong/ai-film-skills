# 两个镜头的接缝审查

用于“A 镜最后一帧 → B 镜第一帧”已经剪在一起、但看起来跳的段落。它不猜原因，只把接缝两侧的证据摆出来：画面、声音、规格、动作方向。

## 1. 先分类，再判

| 边界类型 | 合格标准 | 不合格信号 |
|---|---|---|
| 同镜续接（同一动作被拆两段） | 画框、主体位置、动作阶段、摄影速度、声场连续 | 主体瞬移、动作重演、速度突变、底噪重置 |
| 同场换视点 | 轴线同侧、视线对得上、光源方向一致、空间锚点不矛盾 | 越轴、视线反向、背景换房间、光从另一侧来 |
| 叙事跳跃（时间/地点变化） | 观众能看懂为什么跳；允许硬切 | 没有时间/因果提示，纯靠观众猜 |

先写清这是哪一类。**用“同镜续接”的标准去要求正常切镜，会误判；用“正常切镜”放过同镜断裂，会漏判。**

## 2. 五维检查

1. **身份**：两侧是否同一角色、同一发型/眼镜/胡须/服装；换没换脸。
2. **空间**：背景锚点（墙、门、窗、桌沿、灯位）是否同一方位；有没有换房间。
3. **轴线与视线**：A 看画面右，B 是否从画面左回看；摄影机有没有越到连线另一侧。
4. **动作**：A 末帧的手/身体/道具位置，B 首帧是否接得上；有没有动作重演或跳步。
5. **声音**：切点前后 0.3–0.5 s 的响度、底噪、房间声是否连续；有没有在字中间切、爆音、鬼声。

## 3. 送检方式

- 画面：A 的最后一帧 + B 的第一帧，左右并排，带镜号和时间码。
- 声音：A 的最后 1 s + B 的最前 1 s，成对送。
- 提示词只问接缝，不要问整段：

> 左图是 A 镜最后一帧，右图是 B 镜第一帧。判断：1) 是否同一角色与造型；2) 空间与光源是否连续；3) 视线与动作方向是否接得上；4) 是否有重复帧、跳变或换脸。逐项给证据，没有就说没有。

## 4. 判定

- 同镜续接出现主体瞬移、动作重演、声场重置 = blocker。
- 同场换视点出现越轴、背景换房间、光源反向 = blocker。
- 叙事跳跃没有时间/因果提示 = major。
- 轻微曝光差、景别变化 = minor，不阻断。

## 5. 修复顺序

1. 先看切点选得对不对：能不能往前/往后挪 2–4 帧，避开动作最模糊处或字中间。
2. 再补声音：L-cut/J-cut、房间底噪、切点微交叉。
3. 再换素材：重渲 B 的首帧或 A 的尾帧，锚定真实尾帧。
4. 最后才考虑加空镜/转场；不要用叠化掩盖断裂。

## 6. 禁止

- 用“观众不会注意”放行同镜断裂。
- 把正常切镜的景别变化当穿帮。
- 用统一 crossfade 连接两个没有因果的镜头。
- 只看单帧漂亮，不看接缝两侧的关系。
