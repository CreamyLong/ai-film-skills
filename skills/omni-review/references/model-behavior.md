# 模型实测行为与限制

基于 `qwen3.8-omni-flash` 的实测（2026-11-19），其他 omni 模型按同样方法复测后使用。

## 1. 输入能力

| 模态 | 支持 | 备注 |
|---|---|---|
| 文本 | 是 | 中文流畅 |
| 图片 | 是 | 多图可同送；单帧/网格均可 |
| 视频 | 是 | 会解码音轨；5 s/3.2 MB 稳定 |
| 音频 | 是 | WAV；16 kHz 单声道足够 |

视频自带音频可直接转写并对口型，不必先抽 WAV。音轨缺失时它会说听不到，不编造。

## 2. 可靠的任务

- 参考图 vs 单帧的身份判断（能列具体差异）。
- 烧录字幕：帧号、文字、位置都准。
- 同场空间：能指出墙面、徽标、门窗、陈设的跳变。
- 机位：能判固定/摇移及方向。
- 杂音：干净版 + 可疑版成对送，能判类型与起止。
- 重影/拖影：能区分主体与背景，给出秒数。
- 序列叙事：给人物背景后，能指出“谁是谁不清”“无源特写”“轴线混乱”。

## 3. 不可靠的任务

| 任务 | 现象 | 对策 |
|---|---|---|
| 跨帧换脸 | 同一网格里判“同一人” | 必须参考图 + 单帧成对送 |
| 单段音频切点 | 容易答“没问题” | 必须 A/B 成对送 |
| 人群位置变化 | 会写成“空间跳变” | 只认固定陈设/徽标/门窗 |
| 艺术性叠化 | 会报成伪影 | 先说明意图再问 |
| 表演/节奏/台词好坏 | 主观且不稳定 | 不交给模型判 |

## 4. 延迟与规模

| 输入 | 延迟 |
|---|---:|
| 纯文本 | 8 s |
| 单图网格 | 20–90 s |
| 双图身份 | 28–61 s |
| 5 s 视频 | 55–117 s |
| 4 s 音频 | 9–33 s |

整集不要直传；按 10 s 切片或 1 fps 网格。单集 5–8 次调用是成本上限。

## 5. 结果处理

1. 模型输出先原样保存，再人工核对。
2. 核对不符的标 `false_positive`，保留原话，便于评估模型。
3. 同一缺陷至少两个独立证据（如换脸：参考图差异 + 相邻镜对比）才升 blocker。
4. 报告里写清模型名、调用时间、输入文件哈希；模型升级后可复跑对照。
