# 观众复述故事门（Story Comprehension Gate）

逐镜/逐帧审查回答“有没有伪影”；这道门回答“第一次看的观众能不能把这一集的故事讲清楚”。两者互补，不能互相替代。

## 运行

```bash
python3 scripts/story_comprehension_review.py --video 成片/EPxxx.mp4
```

模型是盲看的：不给剧本、不给字幕文本、不给人物表。它只根据画面和声音回答一份固定的 JSON：

- `setting`：地点、几个人、是谁；
- `goals`：每个人想要什么、冲突是什么；
- `events`：按顺序的关键事件，各含原因和结果；
- `turn`：最大转折；
- `cliffhanger`：结尾悬念（没有写 `none`）；
- `confusions`：看不懂、觉得跳、动机不成立的地方；
- `clarity` / `appeal`：故事清晰度、想看下去的意愿，各 1–10。

## 判定

| 条件 | 判决 |
|---|---|
| `confusions` ≥ 3 | `block` |
| `clarity` 或 `appeal` < 6 | `review`（低于 6 再加注原因） |
| `confusions` 1–2 | `review` |
| 其余 | `pass`（仍不等于人工验收） |

## 读法

- **能判断**：故事是否讲清楚、人物目标是否成立、因果链是否断、有没有钩子、哪里困惑。
- **不能判断**：是否好看、是否有新意、表演是否动人；这些回到导演/编剧审查和鉴赏家终审。
- 模型偏宽容，会自己把模糊处补顺，所以必须强制它列 `confusions`，不要只看复述质量。

## 系列级用法

- 每集跑一次，把 `confusions` 与分集大纲对照：大纲里没有解释、但观众困惑的点，就是需要补台词/反应镜的地方；
- 跨集维护一份“观众记忆”（人物、悬念、已知事实），到季终再问“每个人最后怎么样了、主谜团答案是什么”；答不出或答错说明跨集伏笔没建立。
- 它和 `scripts/episode_audit.py` 的画面审查是两层：先过画面门，再过故事门，最后才谈鉴赏家好评。

## 硬规则

- 审查问题正文固定、手工维护，脚本不生成、不拼装、不逐条改写问题；
- 结论必须回到报告里的具体 `confusions` 条目，不允许只引用总分；
- `pass` 只表示盲测观众能复述，不替代完整看片。
