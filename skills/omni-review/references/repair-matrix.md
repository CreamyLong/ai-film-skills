# 从审查结论到技术修复

审查报告只回答“哪里不对”。修复要回到**最早出错的那一层**，不是统一“重渲”。

## 1. 先定位层，再选动作

| 现象 | 最可能的技术根因 | 先查什么 | 修复动作 | 复验 |
|---|---|---|---|---|
| 换脸 / 年龄漂移 / 造型突变 | 参考图不是画面里在画的人；steps 太低；seed 抽坏 | 该镜 `refs` 是否含在画角色 face；audio 说话人是否画外 | 换正确 face 参考；`--steps 8`；换 seed 重渲 | 参考图 vs 单帧身份对 |
| 烧录字幕 / 伪 UI | prompt 里有引号台词或技术规格；seed 抽坏 | `caption_preflight` 是否 review；prompt 是否含 `9:16`/`24fps`/引号 | 恢复官方 `<d>` 标签并核对语言标签；换 seed；必要时改静帧 | 六帧抽检 |
| 同场空间断裂 | 场景参考图用错/缺失；近景没带环境锚 | editlist block 内环境 ref 是否同一张 | 统一场景图；给近景补环境 ref；重渲受影响镜 | 同场 10–12 帧网格 |
| 切点声音断裂/鬼声 | 逐镜电平未对齐；静帧 `tone_from` 指了对白镜；无 L-cut | `audio_continuity_check` 的电平表与 tone_from | 逐镜增益；静帧换无对白源；L-cut 0.2–0.4 s | 切点 A/B 音频 |
| 多指/断肢/重影/漂浮物 | 4 步采样不足；手部/道具交给 H3；seed 抽坏 | 该镜是否手部/道具特写 | 提到 8 步；道具改真实排版静帧；换 seed | 原片 5 s 伪影复查 |
| 序列看不懂/无源特写 | 缺建立镜、反应镜；轴线乱 | 同场镜头顺序与视线 | 补建立/反应镜；重剪；不改台词硬解释 | 整集 12 帧序列复查 |
| 成片被截短 | concat demuxer 丢帧；偏移按音频算 | 成片时长 vs 分镜总时长 | concat filter；偏移用视频流时长 | 重装后时长核对 |
| 反复出现同一缺陷 | 资产/模板层错误，不是单镜 | 至少三镜是否共用同一错参考/错 prompt 写法 | 修资产或写法，再批量重渲受影响镜 | 抽三镜检查是否消失 |

## 2. 修复顺序

1. **资产层**：参考图错了，重渲多少次都没用。先修图/换图。
2. **提示词层**：引号台词、技术规格、负向句，先改写法。
3. **生成层**：steps、seed、首尾帧、参考图数量。
4. **剪辑层**：切点位置、L-cut、反应镜、重装。
5. **声音层**：增益、底噪、交叉。
6. **交付层**：规格、响度、字幕。

**不要从第 6 层倒着修。**

## 3. 修复包

每个问题镜生成一个修复包：

```json
{
  "shot": "09",
  "defect": "identity_mismatch",
  "root_cause": "reference_not_on_screen_character",
  "action": "replace_ref_and_rerender",
  "command": "python3 <生成脚本> --shots 09 --steps 8 --force --out video/v1",
  "verify": "identity pair + caption sheet",
  "reassemble": "python3 <组装脚本> --config edit/editlist.json"
}
```

## 4. 禁止

- 把所有问题都归为“重渲整集”。
- 用后期锐化/磨皮掩盖换脸。
- 用叠化/空镜掩盖空间断裂。
- 用压缩器掩盖切点电平差。
- 没改根因就重复抽卡。
