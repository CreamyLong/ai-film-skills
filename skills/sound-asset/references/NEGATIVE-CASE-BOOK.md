# 反面案例与改写账本

本表用于当前包的定向诊断；案例中的措辞与数值是说明性选择，不是固定要求。只选与当前声音有关的项，不要求读完或输出全部案例。

| 错误写法 | 为什么错 | 正确写法 |
|---|---|---|
| 有磁性的好听男声 | 没有可核对的特征 | 中低音区、略带砂质、语速偏慢、句尾下沉不上扬 |
| 像某位明星/某部剧的主角 | 姓名不是声音描述，且涉及未授权模仿 | 写该类声音的音高区、音质、咬字与节奏特点 |
| 愤怒版音色、悲伤版音色 | 把表演当成身份，结果每种情绪换一个人 | 一个音色源；情绪写在逐句演绎里 |
| 用同一个预设所以一致 | 声源相同不证明输出稳定 | 同文本复测并对照样音，记录结果或标未验证 |
| 张警官 / 老张 / 张队 各配各的 | 同一人被当成三个说话人 | 别名归一到一个编号并在合同列全 |
| 试音文本：“（愤怒地）你给我出去” | 指导语可能被念出来 | 台词与演绎指令分开提交 |
| 参考音频带背景音乐和混响 | 模型会把音乐与空间学进音色 | 干声、单人、无音乐无效果 |
| 环境音：热闹的街道 | 无声源、无层次、可能带可辨识人声 | 近处摊位炉火，中景人群走动的模糊人声，远处车流；无清晰语句 |
| 环境底里有电话铃和敲门 | 会被当成剧情事件并在循环时重复 | 事件单独做成音效，由具体场次放置 |
| 魔法发动的神秘声音 | 每次生成都不同 | 写物理参照、起音与衰减形态，固化首个批准样本 |
| 史诗感配乐 | 无动机、无配器、无法在后文被认出 | 写动机轮廓、调式、速度范围、主奏乐器与结尾方式 |
| 网上找到的录音，可以直接克隆 | 可下载不等于有克隆或商用权 | 记录权利人与授权范围；不明则改用预设或文字描述音色 |
| 文本合同写完，状态改为已批准 | 没有人听过 | 可听项标 not_evaluated，实际样音经用户审听后才批准 |

## 三层排除格式

通用、资产专属、听感三类用于内部查漏。先写清正面设计目标，再针对已知错误保留必要约束；干声样音不追加与空间有关的要求，环境声底不排除它应有的空间感；角色设定里的沙哑、气声、口吃和方言不是缺陷。不将整表粘贴到任务末尾。
