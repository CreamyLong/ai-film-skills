# 选角与试音方法

新建角色音色、换声源或整体重选角时读取。已有批准音色只做局部派生时不必重读。这里形成设计决定与可核对的样音任务；不授权克隆、上传、付费生成或正式配音。

## 1. 从人物推导声音

先回答人物问题，再选声音特征；不从“好听的声音”出发倒推角色。

| 人物事实 | 可听的落点 |
|---|---|
| 年龄与身体 | 音高区、音质的紧/松、气息长短、嗓音磨损 |
| 地域与成长 | 语言、方言底色、口音浓淡、个别字的读法 |
| 职业与社会位置 | 语速、是否习惯被打断、句子是否说完、音量习惯 |
| 性格与当前处境 | 起句快慢、停顿位置、句尾上扬或下沉、是否藏着气声 |
| 与他人的关系 | 对谁放低、对谁抢话；这属于演绎，不进入音色身份 |

写下两到三条“闭眼也能认出此人”的特征作为锁定候选，其余留给表演。特征要能被别人听辨核对：“中低音区、略带砂质、句尾下沉”可以核对，“有故事感”不能。

反差选角可以成立（外形粗粝而声音细软），但要有人物依据并经用户确认；不默认每个角色都取类型化声线。

## 2. 全剧区分度

把同场出现的说话人放在一起看，不逐个孤立设计。

- 至少在音高区、音质、语速习惯三项中的一项上拉开明显差距；只靠情绪不同分不开两个人。
- 对话最多的两个角色优先保证区分；群戏中的次要角色可共用类型，但不与主要角色相撞。
- 同性别同年龄段的角色最容易混淆，逐对做盲听对照：同一句中性文本，两个候选交替播放，听者不看标签能否分辨。
- 设定为同一副嗓子的角色（伪装、双重身份、年轻与年老由同一声源派生）明确记为共用声源，不为区分而另选声音。

## 3. 试音文本

- 用角色会说的话，不用绕口令或新闻稿。优先原创且不含剧透的句子；必须用剧本原句时逐字引用并注明出处。
- 每条写明对谁说、想让对方做什么或相信什么，以及一个能改变听感的具体做法。只写“愤怒地”通常得到大喊，不一定得到这个人的愤怒。
- 中性基准句避免强情绪词，让身份而不是表演被听见。
- 力度上限与下限用同一句或相近句，便于判断是否仍是同一个人。
- 长句包含至少一处必须换气的位置和一个专有名词或数字，暴露气口与读法问题。
- 多音字、人名、外来词、数字读法在文本旁标注期望读法，并在听音时核对。

## 4. 候选对照与批准

1. 每个角色准备两到三个候选声源，用同一条中性基准句生成或录制，文件名标明角色、候选与文本。
2. 先盲听选身份，再看标签；记录选择理由和被淘汰候选的具体问题。
3. 对入选候选补齐样音组，逐条核对是否仍是同一个人。
4. 做一次稳定性复测：同一文本、同一设置再生成，比较两次结果。稳定比单次惊艳重要；只有一次好听的声源不适合长内容。
5. 作品较长时，用一段接近实际长度的连续文本试一次，观察是否出现音色漂移、异常拖长或语速失控。
6. 用户审听并明确批准后才锁定。批准记录写明听的是哪些文件（路径与哈希）。

## 5. 保住已批准的声音

- 已批准样音是源头，单独归档；不要只留在生成工具的临时输入目录里，那里的文件可能被清理。
- 记录复现所需的全部信息：服务与模型版本、预设标识或参考文件哈希、种子、会影响音色的参数。
- 预设标识逐字核对是否在该服务当前可用清单内。标识无效时有的工具不报错而是换成默认声音或跳过该说话人。
- 说话人写法归一：剧本、分镜和配音任务里的名字、简称、称谓、画外音标记都要能映射到同一个编号。映射不上的台词可能被整句跳过。
- 换模型、换服务或参考文件被重新导出后，视为新声源重新对照，不沿用旧批准。

## 6. 可用的测量与其边界

| 测量 | 能说明 | 不能说明 |
|---|---|---|
| 语音识别回读与文本比对 | 是否大致逐字念出、有无明显吞字增字 | 读法是否自然、同音字是否读对、表演是否成立 |
| 说话人相似度 | 两段音频的声纹距离，可发现明显换人 | 是否符合角色设定、情绪下是否仍可信 |
| 电平与响度测量 | 削波、过低、静音 | 音质好坏 |

测量值是证据，不是批准。没有对应工具时写“未验证”，不以“用了同一个声源”代替比对结果。阈值按本项目实际样本确定并记录来源，不照搬别处的数值。

## 7. 常见失败与返回位置

| 听到的问题 | 先查 | 返回 |
|---|---|---|
| 同一角色不同片段像换了人 | 声源或参考是否真的进入每次请求；是否有片段被跳过后保留了模型自带声音 | 路线与绑定 |
| 两个角色分不清 | 区分度对照是否做过 | 选角 |
| 声音年轻/年老得不对 | 人物事实与锁定特征 | 设计依据 |
| 情绪一上来就变声 | 力度上限样音 | 换声源或收窄表演范围 |
| 长段落后半程音色漂移 | 长文本复测 | 路线；拆分生成单元 |
| 念出了括号里的指导语 | 指令与台词是否分开提交 | 任务编写 |
| 部分台词没有声音 | 说话人别名映射；预设标识是否有效 | 合同的别名与声源字段 |
