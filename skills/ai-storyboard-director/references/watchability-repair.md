# 短剧可看性诊断：镜头轮播、节奏平与重音缺失

用于分镜已成立、单镜也能看，但连起来“不好看”的诊断与重写。它处理观看关系、镜头组织和重音分配，不替代资产一致性、生成质量或声音验收。素材思路参考 zenstory-ai/drama-skills 的 `shot-craft`、shuohao-skills 的站位与镜头量化、OpenMontage 的 cinematic edit 方法；以下为本包按 AI 短剧生产重写的规则，不复制其原文。

## 0. 先排除不是分镜的病因

按顺序排除，避免用重写分镜掩盖别的问题：

1. 台词本身不承担行动或潜台词：回剧本/对白层。
2. 人物身份、服装、道具或空间前后不一致：回资产与连续性层。
3. 单个镜头有伪字、手部崩坏、烧录字幕或音色漂移：回生成/声音层。
4. 只有以上都成立，才把“连起来平淡、碎、像台词轮播”归到本文件。

## 1. 按一次攻守组织镜头，不按一句台词组织

**症状**：A 近景一句、B 近景一句，景别和机位几乎不变；每句都切，观众只看到两张脸轮流出现。

**改写**：

- 先找这一段的攻守单元：谁发难、谁接招、谁改变策略、哪句话让权力翻转。
- 一个单元用 5–10 秒的完整画面承载，可以是双人中景、过肩、听者可见的近景，或人物在镜内改变距离。
- 单元内部不切；只有在攻守变化、信息揭示或人物改变策略时切。
- 台词可以画外叠加在听者/空间画面上；逐句时长仍按实际试读或录音核对，不因合镜压缩语速。

**不要**：为了“覆盖台词”给每句配一个新机位；也不要把多个独立机位塞进一次 H3 生成来省调用。

## 2. 重话之后给接招反应

**症状**：抛出证据或宣判句后立刻切下一句台词，听者没有任何反应；冲突像念稿。

**改写**：

- 重话落地后，给受影响一方 2–4 秒反应：僵住、避开视线、下颌绷紧、后退半步、改变坐姿、握紧物件。
- 反应镜可以无台词；声音只留环境、呼吸或一个物件声。
- 反应要完成一件可观察的事：证明话击中、暴露早已知道、改变下一步策略、转移现场权力，或造成连续性后果。
- 不要求每句都有反应镜；只在权力或知情变化处给。

## 3. 每场有主力观看距离，重音才换档

**症状**：全片都是同尺寸头肩近景；或一路越推越近，中段已经把特写用尽。

**改写**：

- 为一场戏选一个主力景别/机位距离，多数时间停在这里；它不是配额，而是观众的稳定观察位置。
- 换档必须有理由：新空间信息、人物关系变化、关键证据、身体动作结果。
- 大特写和大远景是重音，不连续使用；用完回到主力距离。
- 相邻镜头同景别同角度且关系没变时，先怀疑重复，改角度、并镜或插入有作用的反应，不为“多样性”硬切。

## 4. 每集先定三个 Hero Frames

**症状**：每镜平均用力，没有开场、揭示和结尾的记忆点；看完记不住任何画面。

**改写**：

- 在分镜阶段明确三个必须成立的画面：开场画面、核心揭示画面、结尾悬念画面。
- 每个 Hero Frame 写清主体、动作瞬间、空间关系、光线、机位和观众应先看到什么。
- 其他镜头服务这三个画面，不与之争夺重音。
- Hero Frame 不等于大特写；可以是双人关系、空旷空间、背影或一个物件，但必须有明确的观看作用。

## 5. 开场用运动带信息

**症状**：第一镜是空房间、静物或无人定场；观众三秒内不知道谁在动、在哪、要看什么。

**改写**：

- 首镜优先给运动主体：人物推门、拦人、翻档案、逼近、挣脱、追赶。
- 借人物动作带出空间：门、桌、走廊、出口在动作中显现，不单摆空镜。
- 静态细节留到第二落点兑现；如果第一拍必须是静物，让声音或画外动作先建立方向。
- 竖屏短剧不需要每场都从大全景开始；空间清楚时直接进关系。

## 6. 构图量化，一镜一个主运镜

**症状**：提示词只写“近景/中景”，人物站位、视线和焦点随机；一镜里又推又摇又跟，模型只做一个。

**改写**：

每镜至少写清：

| 字段 | 写什么 |
|---|---|
| 焦段与景深 | 例如 50mm 标准、中浅景深；85mm 长焦、极浅景深 |
| 机位 | 对谁、平视/俯仰/侧背、机位高度 |
| 构图 | 中心、三分、对角线、对称；人物在画左/画右 |
| 视线落点 | 对方面部、手中物、画外声源、闭眼 |
| 焦点 | 眼睛看谁、焦点落在哪；两者可以不同 |
| 稳定性 | 固定、微晃、手持；与运镜分开写 |
| 主运镜 | 推、拉、摇、跟、升降、手持跟随，只选一个，并写触发与终点 |

站位在段级写一次：谁在左、谁在右、朝向、距离；后续镜头从这里接。不要用形容词代替构图。

## 7. 声音与画面共同承担重音

**症状**：每句都同样响、同样快；切点只有画面变化，环境声和停顿没有参与；TTS 像读稿。

**改写**：

- 重话前留半拍，重话后让环境声或沉默接住；不要把停顿当空白填满。
- 画面切到听者时，声音可以仍是说话人的尾音；画面切到空间时，声音可以是脚步、纸张或远处声源。避免用重复对白盖接缝。
- 逐句 TTS 不只给音色，还要给这一句的语速、能量、重音词、前后停顿和演绎说明；同一角色只用一个音色源，情绪不靠换参考。
- 具体字段与质量门由配音/声音执行合同负责：逐句记录 pace、energy、emphasis_words、pause_before/after 与 delivery_note，并同时核对实际听感。

## 8. 与生成路线的边界

- 独立镜头分别生成；不用 0 重叠把多个机位塞进一次执行。
- 同一条连续动作超过单次生成上限时，才用正重叠拆分；后段 `[Shot 1]` 先复述重叠区。
- 不能用“多切一镜成本低”作为一次生成多镜的理由；AI 视频里每多一个独立机位就是一次新调用和一次一致性风险。

## 9. 验收

- 每场能说出主力观看距离和至少一次有理由的换档。
- 每集三个 Hero Frames 可被单独指认。
- 重话后至少有一个接招反应，且反应完成了可观察的变化。
- 连续三镜不是同景别同角度同关系。
- 每镜只有一个主运镜，构图字段可被实际拍摄或生成执行。
- 台词时长按实测/试读装得下，未用加速或吞字掩盖。
- 以上成立仍不好看时，回到剧本因果与人物目标，不继续加镜头或转场。
